# 项目 2 · 企业知识库问答系统（RAG）

> 状态：⚪ 规划中 ｜ 对应方向：AI 产品经理 / 智能体 / RAG 知识库
> 这是全套作品里最值钱的一个，面试主战场。

## 1. 问题（Problem）
企业文档分散在群聊、网盘、邮件，员工找一个答案要翻半天；直接问大模型又会胡编（幻觉）。

## 2. 方案（Action）
搭一个知识库问答系统：上传文档 → 向量化入库 → 用户提问时先检索最相关片段 → 拼进 Prompt → 大模型生成答案并附原文引用，杜绝无依据乱答。

## 3. 架构（Architecture）
- 后端：Python + FastAPI
- 向量库：Chroma（本地、零运维起步）
- 模型：通义/DeepSeek Embedding + 对话 API
- 前端：Vue / React（答案带引用来源、可点开原文）
- 部署：Docker + 云服务器 / 内网穿透
- 数据流：上传 → 解析 → 按语义分块 → Embedding → Chroma → 提问检索 → 拼接 → 生成 → 引用溯源
