# 面试问答准备（高频题 + 答题要点）

> 每条先写"面试官想考什么"，再写"你怎么答"。别背，理解后用自己的话讲。

## 一、技术原理题

**Q：你怎么理解 RAG？和直接调大模型有什么区别？**
- 考点：是否真懂 RAG 价值
- 答：直接问大模型容易幻觉、知识过时。RAG 先检索权威文档片段，再让模型基于片段回答并引用，答案有据可依。适合企业内部知识问答。

**Q：向量检索是怎么做的？Embedding 是什么？**
- 考点：原理是否清楚
- 答：Embedding 把文本转成向量；用户提问也转向量；在向量库里算余弦相似度，取最相近的片段作为上下文。

**Q：如果模型回答错了，你怎么优化？**
- 考点：排障思路
- 答：先看检索有没有召回正确片段（Top-K、分块策略）；再看 Prompt 是否约束"只基于给定内容回答"；再看模型温度；最后加人工反馈闭环。

**Q：Function Calling 是什么？你在项目里怎么用？**
- 考点：Agent 基础
- 答：让模型输出"要调哪个函数 + 参数"，由代码执行再回传结果。可用于让 Agent 查 MySQL、调外部 API。

## 二、工具平台题

**Q：Coze 和 Dify 有什么区别？什么时候用低代码，什么时候必须写代码？**
- 考点：选型判断
- 答：低代码出原型快、给非技术同事演示方便；但要接复杂业务逻辑、自定义检索、企业系统集成时，必须写代码（FastAPI + 向量库）。我会两者都做，并写对比文档。

**Q：你用过影刀 RPA 吗？做过什么？**
- 考点：自动化落地经验
- 答：用影刀 + Python 做过电商订单对账、商品信息批量整理。录屏可演示。

## 三、业务与软技能题

**Q：业务方说不清需求，你怎么办？**
- 考点：需求调研能力（实施岗权重高）
- 答：不问他"要什么功能"，用 Mom Test 问真实行为——上次怎么做的、花多久、哪步最烦。再用 JTBD 收敛成方案，先出原型让他看偏差。

**Q：你怎么评估一个 Agent 的效果？**
- 考点：效果意识
- 答：建测试用例集 + 指标体系（准确率、召回率、幻觉率、耗时、成本）；做 A/B 或人工评测；持续迭代。

**Q：你学历是大专，为什么投这个岗？**
- 考点：自信 + 作品
- 答：直说学历，但亮作品——三个可演示项目从需求到部署全自己走通，GitHub 和演示链接能现场打开。我认为能力比学历更该被看。
