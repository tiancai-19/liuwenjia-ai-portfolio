# 项目 1 · AI 简历优化 + 模拟面试系统

> 状态：🟡 开发中 ｜ 对应 JD：极限怪兽 AI 提效工程师、摩基 AI 产品经理

## 1. 问题（Problem）
投 AI 岗时不会写简历突出项目与成果，面试临场慌、从没真练过，身边没人帮改、没人模拟面。

## 2. 方案（Action）
做一个单页 Web 工具：粘贴简历文本 → AI 按目标岗位重写并标注"为什么这么改" → 再基于简历 + 岗位出 5 道面试题逐题问答 → 结束给评分与改进建议。

## 3. 架构（Architecture）
- 前端：HTML / CSS / JavaScript（已会，AI IDE 生成骨架）
- 大模型 API：DeepSeek / 通义千问（文本生成 + 流式输出）
- 部署：GitHub Pages / 魔搭社区（纯前端直连 API，或加极薄中转层保护 key）
