# 影刀 RPA · 商品上新回写流程（设计文档）

> 状态：📐 设计已出，运行需本机装影刀客户端（社区版免费，影刀官网下载）。本 Demo 阶段未录制/导出流程文件，文档是面试用的"我有完整设计"的证据。

## 1. 为什么需要这段流程

子工具①（AIGC 工作台）只解决了"批量生产图文素材"。距离真正上新还差最后一步——**把这些素材写进拼多多/抖店/淘宝商家后台**。这一步是高度重复且规则化的，恰好是 RPA 的强项。两段串起来就是完整的"AI 生成 + 自动化上新"闭环：

```
   ⑤ 批量模式（Excel 导入）
            │
            ▼
   智谱 GLM + CogView 生成 标题/卖点/详情/主图
            │
            ▼
   落"待上新队列"（localStorage 或 MySQL/飞书多维表）
            │
            ▼
   影刀 RPA 定时拉取 → 登录商家后台 → 逐条填字段 + 上传主图 → 提交
            │
            ▼
   回写"已上新商品 ID + 上架时间"到队列
```

## 2. 触发方式（任选一种）

- **定时触发**：每天 09:00 / 14:00 各跑一次（影刀自带"计划任务"）
- **事件触发**：⑤ 批量模式生成完成后，点"已生成？立即回写"按钮触发
- **手动触发**：运营每天上班点一次"开始回写"

实战推荐 **定时 + 手动兜底**：定时偶尔抽风、手动能补跑。

## 3. 输入数据格式（与 ⑤ 批量模式同构）

影刀读取一个 CSV/JSON 队列（路径示例：`D:\ecom\pending_uploads.csv`），每行字段：

| 字段 | 类型 | 来源 | 必填 | 备注 |
|---|---|---|---|---|
| `sku_id` | string | 自生成 | ✓ | 唯一标识 |
| `title` | string | GLM 生成 | ✓ | 商品标题 1（用 titles[0]） |
| `selling_points` | string | GLM 生成 | ✓ | 3 条用 ` / ` 拼起来塞详情前段 |
| `description` | string | GLM 生成 | ✓ | 详情正文 |
| `category` | string | 用户输入 | ✓ | 类目 |
| `main_image` | string | CogView 生成 | ✓ | 主图本地路径（先下载到 `D:\ecom\images\sku_id.png`） |
| `keywords` | string | 模板提取 | | 搜索关键词，逗号分隔 |
| `price` | number | 模板默认 | ✓ | 走模板默认值 |

> **这份队列文件现在由网页端直接产出**：点 ④ 模板库的「导出为 Excel（交付物）」按钮，
> 得到 `模板库导出_YYYY-MM-DD.xlsx`，每行含 `name / cat / title1-3 / point1-3 / description / imagePrompt`。
> 影刀读取时按列名映射：`title` ← `title1`；`description` ← `point1 + '\n' + point2 + '\n' + point3 + '\n\n' + description`。
> 也就是说**网页导出 → 影刀回写**这条链路在字段层面已经对齐，不需要额外转换脚本。

> ⑤ 批量模式目前是 localStorage。要接影刀，要么在网页加个"导出 CSV"按钮（推荐，成本极低），要么用飞书多维表 / 微信文件助手做中转。

## 4. 影刀指令清单（按顺序）

下面以"抖店开放平台商家后台"为例，其它平台字段名不同但流程一致。

### 步骤 1 · 启动浏览器 + 登录
1. **打开网页** → 抖店商家后台登录页
2. **等待元素出现** → 「账号」输入框（超时 10 秒）
3. **输入文本** → 账号（从 `config.ini` 读，**不写死密码**）
4. **输入密码** → 密码
5. **点击** → 「登录」按钮
6. **等待元素出现** → 「工作台」侧边栏（说明登录成功）
7. **截图存档** → 登录后页面，保存到 `logs\login_<时间>.png`

### 步骤 2 · 进入商品上新页
1. **点击** → 「商品」菜单
2. **点击** → 「商品管理」
3. **点击** → 「发布商品」或「新建商品」
4. **等待元素出现** → 商品标题输入框

### 步骤 3 · 填字段（循环 CSV 每行）
对每一行 CSV 数据：
1. **输入文本** → 标题输入框 ← `row['title']`
2. **输入文本** → 类目（先点类目选择器，再搜 `row['category']` 选第一项）
3. **输入文本** → 详情编辑器 ← `row['selling_points']` + `\n\n` + `row['description']`
4. **输入文本** → 搜索关键词 ← `row['keywords']`（如有）
5. **设置值** → 价格 ← `row['price']`
6. **上传图片** → 「主图」上传按钮 → 选本地文件 `row['main_image']` → 等待上传完成（轮询「已上传 X/1」）
7. **点击** → 「保存为草稿」或「立即上架」（按 config 决定）
8. **等待元素出现** → 成功提示框 / 新建按钮可点（说明保存成功）
9. **关闭** 当前详情/弹窗，回到「发布商品」初始页
10. **更新 CSV**：把这一行的 `sku_id` 写入 `done_uploads.csv`，原 CSV 删这一行

### 步骤 4 · 异常处理
- 任意一步抛错 → 截图存档到 `logs\error_<时间>.png`
- 当前行不删除，加到 `failed_uploads.csv`，含失败原因
- 飞书/微信发消息给运营（影刀支持）
- 继续下一行

### 步骤 5 · 收尾
1. 全部行处理完后，**关闭浏览器**
2. 发消息：本次成功 X 条 / 失败 Y 条
3. 移动 `pending_uploads.csv` 到 `archive\pending_uploads_<日期>.csv`

## 5. 异常分支决策表

| 异常 | 处理 | 兜底 |
|---|---|---|
| 登录失败（验证码/密码错） | 截图 + 通知运营 + 终止 | 运营手动登录后手动触发 |
| 元素找不到（界面改版） | 截图 + 当前行进失败队列 + 继续 | 录屏人工诊断后再修 |
| 上传主图失败 | 重试 1 次，再失败进失败队列 | 跳过该商品继续 |
| 保存按钮点了但没反应 | 等待 5 秒后重试 1 次 | 进失败队列 |
| 浏览器卡死 | 影刀自带超时，超时后强杀重启 | 通知运营 |
