## 子工具 ① 商品图文 AIGC 工作台（✅ 已可演示）

### 1. 问题（Problem）
电商运营上新时，商品标题、卖点文案、主图重复制作、耗时长、质量不稳；同一商品常需多版文案做 A/B。

### 2. 方案（Action）
纯前端单页工具：输入商品名 + 类目 + 卖点 → 大模型生成 3 版标题 / 3 条卖点 / 详情 + 主图提示词 → 文生图出主图 → 满意的组合收藏进模板库复用。

### 3. 架构（Architecture）
- 前端：纯 HTML / CSS / JavaScript（单文件，无构建）
- 文案模型：智谱 GLM-4.7-Flash（open.bigmodel.cn，免费、200K、OpenAI 兼容）
- 图像模型：智谱 CogView-3-Flash（免费文生图，¥0/张，同账号同 Key）
- 批量解析：SheetJS（`xlsx.full.min.js`，CDN 引入，前端解析 xlsx，不上传文件）
- 调用：浏览器 `fetch` 直连智谱开放平台，无后端
- Key 安全：仅存浏览器 `localStorage`（密码掩码），不进仓库/服务器
- 模板库：收藏的组合存 `localStorage`（演示用；生产可换 MySQL）

### 4. 效果（Result）
- 单商品模式：一次输入出 3 标题 + 3 卖点 + 详情 + 主图提示词 + 主图；文案可一键复制，主图可一键下载
- **批量模式**（⑤）：上传 xlsx（列名 `name/cat/points`）→ 循环生成全部商品文案，**可选同时生成主图**；支持逐行勾选/编辑、进度条、可中途取消（AbortController 真断请求）；每条结果可单独收藏 / 复制 / 下载主图；失败项支持「重试这条」与「重试 N 条失败项」两种粒度
- **模板库**（④）：收藏的模板支持**载入到 ① 重新生成**（名称/类目/卖点自动回填）、**复制文案**、**删除**——"收藏成模板复用"是闭环，不是单向存档
- **模板库导出 / 导入**（④）：收藏成果可一键导出为 xlsx 交付物（每行含商品名/类目/3 标题/3 卖点/详情/主图提示词），直接给运营复制上新，或作为下游自动化流程的输入文件；编辑过的表格可再导入回模板库，实现备份 / 换机迁移 / 批量改文案
- 主图：CogView-3-Flash 生成，默认带 AI 水印（生产环境签去水印声明可关）；**图链 30 天失效，页面提供下载按钮 + 失效提示**
- 在线演示：https://tiancai-19.github.io/liuwenjia-ai-portfolio/project-3-ecommerce-rpa/

### 5. 踩坑（Lesson）
- **图生成较慢**：CogView-3-Flash 免费档可能排队，前端设 120 秒超时 + 重试提示，避免白等
- **免费档限速**：GLM 约 1 次/秒、图像也可能 429。**429 触发后有 2-3 秒冷却**，光靠 `sleep(1100)` 避不开，所以 `callChatWithRetry()` 统一做了 catch 429 → 等 2.5 秒 → 自动重试 1 次，单商品和批量共用
- **批量模式限速**：批量循环里每次 API 调用之间 `sleep(1100)`；单次失败不中断整批，已生成的保留
- **失败可重试**：失败的行会挂「重试这条」按钮单独重跑；批量结束后底部还有「重试 N 条失败项」一键重跑全部失败项，成功后汇总按钮（收藏全部 / 导出）会自动按新的成功数重绘
- **xlsx 列名兼容**：批量模板列名同时支持 `name/cat/points` 与 `商品名称/类目/核心卖点`；列名带空格也兼容
- **图像 URL 有效期**：智谱返回图链 30 天有效 → 加了「下载主图」按钮（`fetch → blob → a[download]`；跨域受限时兜底为新窗口打开手动另存），并在页面提示及时留存
- **剪贴板 API 限制**：`navigator.clipboard` 在非 HTTPS / 本地 `file://` 打开时不可用 → `copyText()` 做了 `execCommand('copy')` 兜底，保证 http 和本地打开都能复制
- **原型≠作品**：本工具接的是真实双模型 API + 本地模板库，不是 easy-vibe 的假数据原型

### 6. 运行（Run）
```bash
cd project-3-ecommerce-rpa
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```
- 在线演示：https://tiancai-19.github.io/liuwenjia-ai-portfolio/project-3-ecommerce-rpa/
- 使用（单商品）：填 Key 并保存 → 点「一键填充示例」→「生成文案」→「复制全部文案」或「生成主图」→「下载主图」→「收藏到模板库」
- 使用（复用模板）：④ 模板库 →「载入到①」把历史模板回填到输入框 → 改几个字 →「生成文案」重新出一版
- 使用（批量）：点「下载模板」拿到示例 xlsx → 填好商品列表 → 上传 → 勾选/编辑 → 选「同时生成主图」→「开始批量生成」→ 完成后「全部收藏到模板库」或「导出本批结果为 Excel」
- 使用（导出/导入）：④ 模板库 →「导出为 Excel」拿到成果表 → 本地可编辑 →「导入 Excel」批量更新回模板库
