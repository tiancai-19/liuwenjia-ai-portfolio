# 项目 3 · 电商运营自动化工具集

> 状态：⚪ 规划中 ｜ 对应 JD：极限怪兽 AI 自动化提效工程师（最对口）
> 包含 3 个子工具，分别打不同 JD 关键词。

## 子工具 ① 商品图文 AIGC 工作台（核心）
- 来源案例：https://datawhalechina.github.io/easy-vibe/zh-cn/stage-1/building-prototype/
- **注意**：原案例只是前端原型（假数据、无真实 AI、无后端），必须自己升级：
  - 接真实 API：LLM 写标题/卖点文案 + 文生图生成主图
  - 模板库落库：SQLite / MySQL，不能只放前端 state
  - Excel 批量导入商品 → 批量生成图文草稿 → 收藏/套用模板（支持 A/B 变体）
- 技术栈：React/Vue + Tailwind + 大模型 API + SQLite/MySQL

## 子工具 ② 订单对账自动化（升级旧 P1 跨平台对账）
- 旧 P1 已用 Python + pandas + MySQL 跑通，覆盖多平台订单格式
- 升级点：加 AI 异常识别 / 差异原因自动分类 / 生成对账报告
- 保留原因：真实跑通的数据处理项目，证明 Python/SQL 基础，对上摩基 JD 的"SQL/数据处理"

## 子工具 ③ 客服常见问答 bot
- Coze / Dify 搭建，接知识库
- 覆盖常见客诉自动应答，降低人工重复劳动

## 六段式框架（整体）

### 1. 问题
电商运营中商品图文制作、订单对账、客服回复重复性高，人工耗时且易错。

### 2. 方案
用 AI + RPA 把三类重复流程自动化：AIGC 做图文、pandas 做对账、智能体做客服。

### 3. 架构
- 前端：React + Tailwind
- 自动化：影刀 RPA + Python（pandas / openpyxl）
- AI：Coze/Dify bot + 大模型 API
- 数据：SQLite/MySQL

### 4. 效果
- 待填：图文制作时间节省？对账准确率？客服自动回复覆盖率？

### 5. 踩坑
- 待填：文生图质量与成本权衡？影刀流程稳定性？

### 6. 运行
- 待填：录屏链接 + 代码仓库
